Change the wait.

The number inside delay() tells the Arduino how long to wait. Shorter waits make a faster blink.

BEFORE YOU START

A few good
questions.

Do we need an Arduino kit?+

No. You can explore the 3D workbench and test the code in your browser. When you’re ready to build physically, the first lesson uses parts from the official Arduino Uno R3 Starter Kit.

What can kids change in the code?+

The first lesson has a guided editor with three blink timings. It changes both delay instructions in the sketch. It isn’t a free-text compiler; you can copy or download the sketch to use in the Arduino IDE.

Can we send the code to a real board?+

Yes, the app includes an uploader for a classic Uno R3. Pass the virtual test, have a grown-up check the wiring, then connect over USB using desktop Chrome or Edge. Physical uploads still need a hands-on hardware check. Other boards aren’t supported by this lesson.

Does it work in Safari?+

The lessons, 3D view, and simulator work in Safari. Direct USB upload needs Web Serial, which Safari doesn’t provide. You can download the sketch for Arduino IDE or use desktop Chrome or Edge to connect.

Is progress saved?+

A parent account is required to open the lab. Child profiles save to an account so the parent can follow progress and the learner can continue on another device. Parent practice stays on the device. Kid login links expire after five minutes and work once.
