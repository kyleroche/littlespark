A LITTLE PREVIEW

Change the wait.
Find your rhythm.

The number inside delay() tells the Arduino how long to wait. Shorter waits make a faster blink.

Try it here. In the lesson, Sparky the hedgehog explains the wait lines and previews a faster or slower blink. You choose whether to apply his change, and can undo it. Then test the program on the virtual board.

BEFORE YOU START

A few good
questions.

Do we need an Arduino kit?+

No. Fruit Piano has a virtual practice mode with on-screen keys. You can also explore the Arduino 3D workbench and test the code in your browser. When you’re ready to build physically, the first lesson uses parts from the official Arduino Uno R3 Starter Kit.

What can kids change in the code?+

Blink and Traffic Lights use guided timing controls: Blink changes two waits; Traffic Lights changes three waits while keeping the red → green → yellow order. Push-button Light offers two output rules. Sparky offers hints and previews a change before you apply it, with Undo to go back. It changes both delay instructions in the sketch. It isn’t a free-text compiler; you can copy or download the sketch to use in the Arduino IDE.

What can kids make with Makey Makey?+

Start with Fruit Piano. Conductivity Detective adds predictions and a saved experiment notebook. Game Controller turns four foil pads into arrows for Spark Hunt. Each has a virtual practice mode and a real-board keyboard mode. These modes cannot identify a physical board or check real wiring.

What comes after Blink?+

Traffic Lights adds two more LEDs. Each has its own 220 Ω resistor. The virtual test checks red → green → yellow, the wait times, and that two lights never stay on together. Push-button Light then adds an input and two output rules. A grown-up still needs to check your real wiring.

Does Fruit Piano work with a real Makey Makey?+

Yes. It acts like a USB keyboard. In step 7, choose Real board / keyboard, turn sound on, and Focus piano. The SPACE, LEFT and UP inputs play notes. A normal keyboard works too; receiving a key cannot verify your wiring. This flow does not need Web Serial. Use a computer with a USB connection.

Can we send the code to a real board?+

Yes, the app includes an uploader for a classic Uno R3. Pass the virtual test, have a grown-up check the wiring, then connect over USB using desktop Chrome or Edge. Physical uploads still need a hands-on hardware check. Other boards aren’t supported by this lesson.

Does it work in Safari?+

The lessons, 3D view, simulator, and Fruit Piano keyboard input work in Safari. Direct Arduino USB upload needs Web Serial, which Safari doesn’t provide. You can download the sketch for Arduino IDE or use desktop Chrome or Edge to connect.

How do family profiles work?+

Sign in with a parent email and open Family to create a profile for each child. Make a temporary link or QR code for the child to open on their own device. Each link works once and expires after five minutes; the signed-in child can keep building after it expires. Parents can rename profiles, see progress, and sign out a child’s devices. Follow the family setup guide.

Is progress saved?+

The lab requires a signed-in parent or child profile. Children’s completed steps and settings sync to their own profiles. Parents can follow them in Family. Practice on a parent profile stays in that browser. See the progress guide.
