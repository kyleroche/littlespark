HELLO, GROWN-UP

        
A small adventure, together.

        

          This first lesson uses a classic Uno R3, a breadboard, a standard LED,
          a 220 Ω resistor, and two jumper wires.
        

        

          Follow each animated step with the board unplugged. Check the LED’s
          long leg connects through the resistor to D13, and its short leg
          connects to GND. Use USB power for this activity.
        

        

          The browser runs the actual precompiled AVR program in an emulator.
          After the test passes, the identical firmware can be uploaded using
          Web Serial and the Uno’s bootloader. Physical uploads still need a
          hands-on check.
        

        

          Progress stays in this browser. There are no accounts, ads, or
          tracking scripts. The code is intentionally guided; free-form
          programming is a later adventure.
